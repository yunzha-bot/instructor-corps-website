## 功能架构

官网 → 登录/激活 → 队员工作区 → 本人档案 / 成长历程 / 我的学习 / 课程中心 / 心理支持。

同一账号按获授权限进入管理工作区，管理申请、成员组织、课程、训练与考核、官网内容、媒体、角色和公告；私人心理记录不进入该后台。

- [概念数据模型、独立私人域、权限边界、后端路线与实施顺序](03-数据权限与后端预研.md)

# 教官大队｜档案交互原型 v3

直接浏览：http://127.0.0.1:4173/?scene=archive 。默认 `/` 含原站开场；服务器状态应在每次会话核实。

## 最新修改

用户指出第一版平面动画、第二版简化三维板仍不像参考，并明确要求同样的动效与样式。当前直接迁移 RhineLabUI 的完整场景、GLB 模型、磨砂透射、景深／AO／灯光、镜头、双环内构、文字和编号滚动、正文解密、模型查看器及响应式界面。

来源固定为 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI) 的 `12cc5e4013acb9408f753ff71de6b8492299b7c8`。原有三套首页、三张档案稿和旧实现都保留。

所有启动入口均在加载页等待三维准备完成：预加载实际档案文字、按正式尺寸预热阵列及归位／抽出材质，并等待 GPU 完成绘制后允许进入。加载页等待可能变长，目的是减少进入后补编译引起的卡顿；详见 [首帧性能规格](MOTION_SPEC.md)。回归命令为 `node scripts/check-startup.mjs`，实测结果见 `qa/startup/checks.json`。

运动边缘的抗锯齿现在覆盖实际使用的离屏合成目标；通过 `node scripts/check-motion-aliasing.mjs` 对照旧路径与修正路径的微小位移画面，避免只检查静止截图。具体采样预算与测试口径见 [动效规格](MOTION_SPEC.md)。

设置面板顶部提供「低／中／高／极高」四档滑块和档位按钮。默认低档，旧高开销配置首次迁移为低档；拖动预览、释放应用，选择自动保存。低档使用简化材质并关闭阴影／AO／景深；其余档位逐步增加细节，均有独立像素预算。2× 超采样仅保留为手动高级选项。回归命令：`node scripts/check-quality-tiers.mjs`。

## 滚轮浏览

在阵列区域向下滚动，连续移向下一块档案；反向滚动返回上一块。小幅触控板输入会累积；停止后缓动吸附。轨道先移动，焦点随后按实际位置更新。方向键和按钮仍可用，但不再是主要浏览方式。进入详情后滚轮用于阅读，不切换档案。

## 可操作内容

- 五列循环阵列，拖动、滚轮、键盘、检索与分类。
- 抽取、解密、阅读页签、返回、重播开场、动态与画质设置、亮暗主题。
- 完整模型查看器：旋转、平移、缩放、清晰／磨砂、拆解／重组和复位。
- 演示资料编辑并保存在本浏览器、收藏、导出本项目演示文本。
- 手机／平板沿用原站的响应式布局，内部阅读区域可滚动。

所有身份与条目是演示，缺少的组织信息保持待补充。40个索引条目用于观察原站五列×八项的交互，不代表存在40个真实队员或真实记录。没有真实账号、数据库、跨设备同步或隐私保障。心理记录没有接入。

## 代码与来源

- `src/rhine/`：原项目代码及少量产品适配；`wheel-track.ts` 为本轮新增的连续滚轮轨道。
- `src/rhine/data.ts`：教官大队演示内容与原站对照内容切换；`src/data.ts`：浏览器内虚构个人资料。
- `src/entry.ts`：当前入口；`?view=profile` 保留旧版档案稿原型；`?reference=1` 是原站同内容核验夹具。
- [动效规格](MOTION_SPEC.md)、[第三方声明](THIRD-PARTY-NOTICES.md)、[验收记录](design-qa.md)。

所有运行资产保存在本地。MiSans及依赖保留其许可。仓库未附的 Novecento 字体不从作者站点拷贝，以仓库自带的字形图形替代。原型关闭生产PWA缓存；不复制原站的真实认证含义。
